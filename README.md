# Olist E-Commerce SQL Analytics Project

An end-to-end **SQL Server analytics project** built on the Brazilian Olist e-commerce dataset.

The project focuses entirely on **SQL**: exploratory data analysis, data cleaning, normalization, analytical views, indexing, business analysis, validation, and query performance testing.

## Project Objective

The objective is to transform raw Olist e-commerce data into a reliable analytical SQL environment that can answer practical business questions while demonstrating real SQL engineering skills.

```text
Raw Olist Data
      │
      ▼
01 - EDA
      │
      ▼
02 - Cleaning
      │
      ▼
03 - Normalization
      │
      ▼
04 - Conditions / Analytical Logic
      │
      ▼

      │
      ▼
06 - Indexing
      │
      ▼
07 - Business Analysis
      │
      ▼

      ▼
09 - Performance Testing
```
